# Locally bundled fonts

- Instrument Sans Latin WOFF2 subset, weights 400–600, sourced from Google Fonts: https://fonts.google.com/specimen/Instrument+Sans (upstream project: https://github.com/Instrument/instrument-sans). License: `Instrument-Sans-OFL.txt`.
- IBM Plex Mono Latin WOFF2 subset, weight 400, sourced from Google Fonts: https://fonts.google.com/specimen/IBM+Plex+Mono (upstream project: https://github.com/IBM/plex). License: `IBM-Plex-Mono-OFL.txt`.

The WOFF2 subset files are self-hosted by Next.js through `next/font/local`; no build-time or runtime font request is made to a third party.
